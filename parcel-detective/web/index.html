Meet your investigation desk.

A useful next step, with the records to back it up.

01

Choose the next source

In AWS mode, Strands Decider 2B chooses which evidence source to inspect next. Its input includes the case report and the records collected so far.

02

Keep the trail

Tools read fictional scan history, dispatch records and shift notes. Every retrieved record has an ID and a timestamp. The host requires all three sources in this first version.

03

Explain with evidence

Conservative rules establish a provisional finding. Amazon Bedrock explains it with record IDs. IDs are checked; workers still review the wording and the parcel location.

04

Ask for a physical check

Missing or conflicting evidence produces a check request for the worker. The app never claims to have physically found a parcel or silently closes a case.
